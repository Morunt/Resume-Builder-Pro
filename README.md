#  Resume Builder Pro

## 🇬🇧 English

This is my resume builder.  
Made on pure HTML / CSS / JS, without frameworks and backend.

Started as a simple idea “just make a CV quickly”,  
but then I kept adding features… and now it’s a full app

Some parts are clean, some… not really.  
But overall - it works, and that’s what matters.

---

###  What it can do

- Create multiple resumes
- Switch between templates (Classic / Modern / Minimal / Dark)
- Live preview while editing (no refresh)
- Photo editor (zoom / position / border radius)
- Skills / Experience / Portfolio blocks
- Drag & drop block order
- Export / import JSON
- Download as PDF
- Everything saves in browser (localStorage)

---

### Tech

- HTML
- CSS
- Vanilla JS
- html2canvas + jsPDF

---

### How to run

Just open:

index.html

No installs, no build tools, nothing.

---

### Notes

- Everything is saved in localStorage (so don’t clear browser)
- PDF export can be a bit heavy sometimes
- Code is not perfect - was writing, then refactoring, then fixing bugs… and repeat

---

### Files

- index.html → layout
- style.css → styles
- app.js → logic (yeah… everything in one file)
